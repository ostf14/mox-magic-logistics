## 1. ФИКСИРОВАННОЕ ВРЕМЯ

```ts
// lib/now.ts
export const NOW = new Date('2026-08-01T09:12:00+02:00')
```

**`Date.now()` и `new Date()` без аргументов запрещены во всём проекте.** Любой расчёт времени идёт от `NOW`.

Причина: страница должна быть детерминированной. Закрытая мастерская всегда закрыта, трекинг всегда сходится с конфигуратором, скриншоты воспроизводимы.

## 3. РАСЧЁТ

Одна чистая функция, отдельный файл, **без импортов React**.

```ts
// lib/calcOrder.ts
export function calcOrder(input: {
  spellId: string
  tariffId: string
  optionIds: string[]
  now: Date
}): OrderCalc
```

```ts
type OrderCalc = {
  waitUntilOpen: number      // минут до открытия мастерской, 0 если открыта
  prepMinutes: number
  deliveryMinutes: number
  totalMinutes: number       // сумма трёх выше
  readyAt: Date
  lines: { label: string; value: number }[]   // строки чека
  total: number
  blockedTariffIds: string[]
  forcedOptionIds: string[]
}
```

### Правила

**Открытие мастерской.** Если `NOW` вне `[opensAt, closesAt)`, `waitUntilOpen` = минут до ближайшего открытия. Иначе 0.

**Блокировка тарифов.** `hazardClass === 4` → `blockedTariffIds: ['foot']`. Причина в подписи: перевозка только с сопровождением чародея.

**Принудительные опции.** `hazardClass >= 3` → `forcedOptionIds: ['insurance']`. Чекбокс отмечен, задизейблен, в чеке строка присутствует.

**Чек.** Позиции в порядке: заклинание → доставка → каждая выбранная опция с ненулевой ценой → сбор службы. Итог суммой.

**`calcOrder` покрывается тестами до того, как написан хоть один компонент.** Минимум: Лунная пыль на грифоне и на портале дают одинаковый `formatDuration`; Ласточка при `NOW` даёт `waitUntilOpen > 0`; класс IV блокирует пешую.

## 4. ФОРМАТИРОВАНИЕ ВРЕМЕНИ

```ts
// lib/formatDuration.ts
```

| totalMinutes | вывод |
|---|---|
| < 60 | `40 мин` |
| 60 … 1439 | `6 ч` — floor до часа |
| ≥ 1440 | `2 суток` — **floor до суток** |

Единственное исключение в склонении: ровно 1 → `1 сутки`. Дальше всегда `N суток`.

**Огрубление до суток обязательно и является продуктовым решением, а не упрощением.** Лунная пыль на грифоне (3240 мин) и на портале (2940 мин) обязаны показать одинаковые `2 суток`. Именно так пользователь видит, что доплата 155 крон ничего не даёт. Никаких пояснительных плашек рядом с этим не добавлять.

### Абсолютное время

```ts
// lib/formatAbsolute.ts
```

Сегодня → `сегодня, к 19:40`
Завтра → `завтра, к 11:00`
Дальше → `вторник, к 11:00`

## 5. СТЕЙТ-МАШИНА

Один объект заказа на всю секцию.

```ts
type OrderState = {
  view: 'config' | 'form' | 'tracking'
  spellId: string
  tariffId: string
  optionIds: string[]
  recipient: { name: string; address: string; when: string; note: string }
  trackingNumber: string | null
}
```

Переходы:
- `config → form` — кнопка «Далее»
- `form → config` — кнопка «Назад к составу»
- `form → tracking` — кнопка «Оформить отправление», генерируется трек-номер `PL-4471-0293`
- `tracking → config` — кнопка «Оформить ещё одно отправление», состояние сбрасывается

Все три вида живут в **одной секции страницы** и меняются на месте. Скролл не прыгает, высота секции по возможности стабильна.

Клики по карточке каталога и по плитке тарифа выставляют соответствующее поле и скроллят к секции заказа.

## 6. ТРЕКИНГ ГЕНЕРИТСЯ

События **не хардкодятся**. Строятся из заказа:

```ts
// lib/buildTimeline.ts
buildTimeline(order, calc) → TimelineEvent[]
```

**Фаза 1 — мастерская.** Заголовок = название и город мастерской заглавными.
- `NOW` — Отправление принято
- `NOW + 8 мин` — Мастерская приступила к изготовлению
- `NOW + waitUntilOpen + prepMinutes` — Заклинание готово, опечатано, ожидает курьера

**Фаза 2 — доставка.** Заголовок = `ДОСТАВКА · {название тарифа}`.
- готовность `+ 4 мин` — Курьер принял груз, печать проверена
- `+ 27 мин` — Отправление в пути
- `+ 44 мин` — Задержка: шторм на переправе, Скеллиге / Курьер ждёт паром, новый срок — `{readyAt}`
- будущее — Прибыло в отделение получателя
- будущее — Вручено

Пройденные события закрашены, текущее подсвечено, будущие серые с прочерком вместо времени.

Смена тарифа в конфигураторе меняет таймлайн. Это проверяется вручную перед сдачей.

Значения предварительные, будут заменены. **Структура обязательна.**

```css
--paper:  #F2EFE9;
--ink:    #1A1A18;
--muted:  #6B6862;
--rule:   #D6D1C7;
--accent: #7B2D26;

--class-1: #8A867E;
--class-2: #A87B2E;
--class-3: #C2571F;
--class-4: #7B2D26;
```

Шрифты подключить через `next/font/google`: интерфейсный + моноширинный. Моноширинный обязателен для трек-номеров, времени в степпере и всех сумм в чеке.

### Жёсткие запреты по стилю

Градиенты. Тени, кроме одной еле заметной на липкой сводке. `rounded-full` и скругления больше 4px. Эмодзи. Декоративные иконки. Цвета вне списка выше. Центрированный текст в блоках длиннее заголовка.

Разделение делается **рамками в 1px**, а не тенями и не фоновыми заливками. Это документ, а не карточный дашборд.
